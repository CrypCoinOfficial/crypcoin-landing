# CrypCoin Assets

This repository is dedicated exclusively to static files used across the CrypCoin project:

- Images (PNG, WebP, SVG)
- Videos (MP4, WebM)
- Icons and other media files

The repository acts as a storage/CDN for CrypCoin’s visual and media resources.  
It is publicly served via Vercel at:

👉 https://cdn.crypcoin.io/assets/
